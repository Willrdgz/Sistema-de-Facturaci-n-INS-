# InVenta

Esta carpeta contiene la aplicación Laravel de ventas e inventario.

La guía completa está en el **[README principal del repositorio](../README.md)** e incluye:

- Funciones, manual de uso y permisos de administrador/vendedor.
- Clonación e instalación en otra laptop con MySQL/MariaDB o SQLite.
- Creación de la primera cuenta administradora.
- Esquema y relaciones de la base de datos.
- Controles de seguridad, respaldos, restauración y publicación.
- Pruebas, mantenimiento, solución de problemas y límites actuales.

Ejecuta los comandos `php artisan`, `composer` y `npm` desde esta carpeta. Consulta la guía antes de inicializar o restaurar la base de datos; el seeder no crea usuarios.
